# framework — jádro

Zatím prázdné. Engine a jazyk (D3, D4) rozhodnou spiky v `spikes/`.

Až se začne: sem patří CLI (`run`, `validate`, `--dry-run`, `runs`),
engine (pořadí kroků, `parallel`, `switch`, `call`, záznam běhu),
adaptéry (OpenRouter chat, Jev, obrázky, MCP), webhook a konformační
scénáře s falešným poskytovatelem.
