# Bezpečnost / Security

Citlivé hlášení neposílejte do veřejného issue ani PR.
Použijte GitHub **Security → Advisories → Report a vulnerability**
([neveřejné hlášení](https://github.com/rychidesign/agencast/security/advisories/new)),
pokud je tato možnost dostupná, nebo jiný neveřejný kanál na GitHubu, pokud jej správce zpřístupnil.
Nepřikládejte přístupové klíče ani osobní údaje.
Odezva, oprava ani termín nejsou zaručené; software je poskytován bez záruky.

Do not post sensitive reports in public issues or pull requests.
Use GitHub **Security → Advisories → Report a vulnerability** when available,
or another private GitHub channel made available by the maintainer.
Do not include credentials or personal data. No response, fix, or deadline is guaranteed.
