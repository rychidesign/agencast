# Security

Do not post sensitive reports in public issues or pull requests.
Use GitHub **Security → Advisories → Report a vulnerability**
([private report](https://github.com/rychidesign/agencast/security/advisories/new))
when available, or another private GitHub channel made available by the maintainer.
Do not include credentials or personal data. No response, fix, or deadline is guaranteed.
