# IG caption — tón značky kavárny Lípa

Tón: klidný, přátelský, tykáme. Žádné vykřičníky, žádná velká písmena pro důraz.

Struktura:
1. První řádek začíná emoji 🌿 a má nejvýš 8 slov.
2. Dvě až tři krátké věty o produktu (chuť, sezóna, kde ho najdeš).
3. Poslední řádek je přesně: `Uvidíme se u okna.`

Hashtagy do captionu nepiš, řeší je samostatný krok.
