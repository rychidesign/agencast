# skills

Skills for coding agents (Claude Code, Codex, OMP) that work *on* AgenCast:
`agencast-run` (validate, dry-run, run, read results) and `agencast-create`
(write agents and scenarios). Install on this host with `skills/install.sh`.

Not to be confused with `workflows/skills/` — those are skills for the agents
*inside* scenarios (loaded by the `skills:` field of an agent).
